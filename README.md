# Estructuras de Datos en Java

Repositorio de proyectos académicos desarrollados durante mi formación en la Licenciatura en Informática.

## Sobre el proyecto

En este repositorio se reúnen diferentes ejercicios y programas desarrollados en Java para aplicar conceptos de estructuras de datos y algoritmos.

El objetivo es practicar la implementación y utilización de diferentes estructuras, comprender su funcionamiento y resolver problemas mediante algoritmos.

## Tecnologías utilizadas

- Java
- Programación orientada a objetos
- Estructuras de datos
- Algoritmos
- Recursividad
- Arreglos
- Matrices

## Contenidos

### Pilas y colas

Implementación y utilización de estructuras de tipo pila y cola.

Archivo:

`src/EstructurasBasicas.java`

### Listas enlazadas

Implementación de una lista enlazada simple, con operaciones de inserción, recorrido y búsqueda.

Archivo:

`src/ListasEnlazadas.java`

### Árboles binarios

Implementación de un árbol binario de búsqueda utilizando inserción, recorrido inorden y búsqueda.

Archivo:

`src/ArbolBinario.java`

### Tablas hash

Implementación de una tabla hash básica utilizando una función hash para almacenar y buscar elementos.

Archivo:

`src/TablasHash.java`

### Grafos

Representación de un grafo mediante una matriz de adyacencia y operaciones básicas sobre sus conexiones.

Archivo:

`src/Grafos.java`

### Algoritmo de Dijkstra

Implementación del algoritmo de Dijkstra para calcular las distancias mínimas desde un vértice de origen en un grafo ponderado.

Archivo:

`src/Dijkstra.java`
